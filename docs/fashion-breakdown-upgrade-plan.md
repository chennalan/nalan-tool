# AI 服装拆解工作台升级方案

分支：`feat/fashion-breakdown-sam2-multiformat`

## 已确认的产品范围

- 识别方式：Gemini 自动语义识别 + 人工框选/移动/缩放/删除。
- 分割方式：SAM 2 根据 Gemini 推荐区域或人工框选提示生成像素级前景掩膜。
- 导出：电商详情图、Editorial 杂志拼贴、社交平台图片。
- 商品真实性：只对原图做裁切、掩膜、缩放、清晰度处理和排版；不生成/重绘商品纹样、颜色、蕾丝、肩带、版型或不可见部位。

## 当前代码基线

现有 `fashion-breakdown.html` 是无构建步骤的单页工具：
- 原图在浏览器内处理；Gemini 通过用户填写的 Base URL / Model / Key 调用。
- Gemini 当前只返回归一化矩形框，并非像素级分割。
- 手动框选与拖动、细节缩略图、单张 4:5 海报和 2400×3000 PNG 已存在。
- 当前没有 SAM 2 推理运行时，也没有电商/社交多规格导出。

## 技术分层

### 1. Gemini 语义识别
输入：压缩后的当前商品图。
输出：严格 JSON 的可见部位建议，含 `label`、`x/y/w/h`、`confidence`、`reason`。
校验：坐标归一化、范围裁剪、重叠去重、低置信度提示；不把不可见细节作为事实。

### 2. SAM 2 像素级分割
SAM 2 不放在 Cloudflare Pages 浏览器端硬跑。首期采用可替换的推理适配器：
- 前端向用户配置的 SAM 2 推理服务发送图片与 box prompt。
- 服务返回与输入图片同尺寸的单通道 PNG mask（白色=保留，黑色=背景），可选置信度。
- 前端使用 Canvas 将 mask 应用到原图裁切，输出透明背景 PNG；失败时回退矩形裁切，不阻断工作流。
- 服务地址、鉴权方式可配置；不在代码中写入密钥，不创建付费 GPU/云资源。
- 未配置服务时明确显示“尚未连接 SAM 2 推理服务”，不伪装成已完成分割。

建议的请求契约（由后续 SAM 2 服务端实现）：
```json
{
  "image": "data:image/jpeg;base64,...",
  "prompt": { "type": "box", "x": 0.1, "y": 0.2, "w": 0.4, "h": 0.3 },
  "output": "mask_png"
}
```
响应：
```json
{ "mask": "data:image/png;base64,...", "confidence": 0.96 }
```
以上为本项目适配器契约，不代表任意第三方 SAM 2 服务天然兼容。

### 3. 编辑器
- 保留现有手动框选，增加 AI 建议框的可视化与逐项确认。
- 细节卡片可重命名、重新分割、重新裁切、排序、删除。
- 撤销/重做、选区状态、项目 JSON 导入/导出列为增强项。
- 原图始终保留，所有编辑均基于副本。

### 4. 排版与导出规格

| 用途 | 画布比例/尺寸 | 输出 |
|---|---|---|
| 电商详情图 | 3:4，建议 1500×2000 | PNG/JPG |
| Editorial | 4:5，2400×3000 | PNG |
| 小红书/抖音图文 | 3:4，1242×1660 | PNG/JPG |
| 社交方图 | 1:1，1600×1600 | PNG/JPG |
| 社交竖图 | 9:16，1080×1920 | PNG/JPG |

模板包括：主图+细节、细节网格、杂志错位拼贴、极简品牌页。所有画布尺寸由同一套布局数据驱动，避免每种格式各自复制排版逻辑。

## 实施阶段

1. **第一阶段：前端结构与交互**——配置 SAM 2 endpoint、识别建议列表、分割状态、细节资产模型、导出规格选择。
2. **第二阶段：SAM 2 适配器**——实现 box prompt 请求、mask 校验、透明裁切与矩形回退；提供 mock 响应用于无 GPU 测试。
3. **第三阶段：多规格模板**——统一画布渲染器，完成电商、Editorial、社交规格。
4. **第四阶段：质量与安全**——检查原图像素不被改写、透明 mask 边缘、超大图内存、API 错误、跨域、移动端交互、导出尺寸。

## 验收标准

- Gemini 只提供语义与候选区域；SAM 2 返回真实 mask 才显示“分割成功”。
- 人工框选可独立使用；AI/SAM 2 故障时仍可完成矩形拆图。
- 透明 PNG 的尺寸、alpha 通道与 mask 对齐，不拉伸、不偏移。
- 所有导出尺寸与比例准确；同一商品可切换多种模板。
- 默认不上传图片；只有用户主动点击 AI 分析/SAM 2 分割时才向相应配置的服务发送图片。
- API Key 不写入仓库、不放入 URL、不自动持久化；不新增正式数据库写入。
- 只在本分支开发和测试，不合并、不部署正式站点，除非用户另行确认。

## 重要边界

SAM 2 推理需要可运行模型的后端或用户自有 GPU 环境。Cloudflare Pages 仅承载静态前端，不负责运行 SAM 2 模型。RunPod 等 GPU 服务可能产生费用，本次不创建、不启动任何付费资源；待用户提供现有推理服务地址或确认运行环境后再接通真实推理。
