# AI 服装拆解工作台完善方案（不包含 SAM 2）

分支：`feat/fashion-breakdown-sam2-multiformat`

## 产品范围
- Gemini 语义识别：识别真实可见的服装局部，输出候选框和说明。
- 手动编辑：框选、移动、缩放、重命名、排序、删除。
- 本地裁切：使用原图像素生成细节图，不进行 AI 重绘。
- 三类视觉输出：电商详情图、Editorial 杂志拼贴、社交平台图片。
- 多规格导出：3:4（1500×2000）、4:5（2400×3000）、9:16（1080×1920）、1:1（1600×1600）；支持 PNG/JPG。

## 设计原则
1. Gemini 仅分析和推荐区域，不修改商品像素。
2. 所有裁切、排版、导出均在浏览器本地完成。
3. 图片只在用户主动点击 AI 分析时发送至用户配置的 Gemini API。
4. API Key 不写入仓库、不放入 URL、不自动保存。
5. AI 失败时，手动框选仍可独立工作。

## 实施内容
- 多规格画布：按导出比例重排画布，输出真实像素尺寸。
- 模板体系：电商主图+细节、Editorial 拼贴、社交封面/方图。
- 细节资产管理：命名、排序、删除，避免重复裁切。
- 历史操作：细节图增删改与排序支持撤销/重做，最多保留 40 步。
- 项目文件：JSON 保存/恢复，包含原图数据、细节裁切、排版配置与画布布局；不依赖临时 blob 地址。
- 导出：单规格 PNG/JPG、批量逐张导出全部规格。
- 质量控制：检查坐标边界、原图比例、图片清晰度、导出尺寸和移动端适配。

## 后续可选增强
- 快捷键支持（撤销/重做目前提供界面按钮）。
- 多商品批量处理与批量命名。
- 品牌模板预设与自定义字体/Logo。
- Gemini 识别结果增加置信度、区域原因和重复区域合并。

## 验收边界
本次不接入 SAM 2 或其他像素分割模型，不创建 GPU/云端推理资源，不部署、不合并正式版。只在本分支实现与测试。
