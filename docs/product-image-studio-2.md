# 商品图片批量精修工作台 2.0

本地浏览器商品图片工具，包含：
- 批量精修：亮度、对比度、饱和度、锐化和预设。
- 智能尺寸适配：常用平台画布规格、自定义尺寸、完整显示/居中裁切、背景色、轻微阴影。
- 批量加白底：可在尺寸适配中选择纯白背景，并与其他设置一起批量导出。
- 批量水印：文字或 Logo、透明度、大小、角度、位置、平铺。
- 详情图排版：纵向大图、双列拼图、首图大图、品牌详情长图；支持标题、副标题和文件名。
- 当前图导出、队列顺序调整、ZIP 批量导出。

隐私：图片由浏览器本地读取和 Canvas 处理，不上传服务器。JSZip 通过 CDN 加载，因此 ZIP 首次使用需联网。原图不覆盖。

限制：本版是规则式图像处理，不是 AI 增强；锐化采用轻量 Canvas 像素处理，超大图会跳过锐化以控制内存。详情图为基础模板排版，尚不包含拖拽式自由画布和可编辑图层。
